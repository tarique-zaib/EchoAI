\# EchoPrepAI Product Roadmap



> Personal AI Interview Assistant built with Electron, .NET, Python, and Gemini Vision.



\*\*Current Version:\*\* v0.5



\*\*Status:\*\* Active Development



\---



\# Product Vision



EchoPrepAI is designed to become a real-time desktop interview copilot that helps during technical interviews through live transcription, screenshot understanding, resume recall, and AI-assisted explanations.

\# Architecture Principles



\* Electron handles UI.

\* .NET handles orchestration.

\* Python remains the frozen transcription engine.

\* Gemini handles vision understanding.

\* SignalR streams everything live.



\---



\# Development Rules



Every feature follows the same lifecycle.



1\. Design

2\. Build

3\. Test

4\. Check-in

5\. Git Tag

6\. Release



Working code gets frozen before new features begin.
